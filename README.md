# SmartCV Tailor

SmartCV Tailor is an AI-assisted web app concept focused on helping job seekers quickly tailor their CV and cover letter to a specific role while improving ATS compatibility.

## What this repository currently contains

This initial commit turns your concept into an execution-ready MVP blueprint:

- Product requirements and user flow
- Feature definitions and scoring model
- Simple technical architecture
- Suggested API design
- MVP milestones and delivery plan

See `docs/SMARTCV_TAILOR_MVP.md`.
